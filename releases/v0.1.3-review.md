## 已知问题与补偿限制

- 平台 AT、正式签名及正式发布门禁未完成；GitHub 必须保持 Draft，不创建 Git Tag，不得描述为 Stable 或 Android 已正式发布。
- macOS 未 notarize、Windows 未 Authenticode 签名；首次打开可能需要系统手工放行。
- 仓库既有 Rust 格式偏差使 `cargo fmt --all -- --check` 未通过；本次 Native Host 注册源码的独立 `rustfmt --check --edition 2024` 已通过，未将格式检查声明为全库通过。
- Android 本轮新增 contract 是源码与脚本验证，不能代替权限拒绝、保存失败、快速切换、不同 peer 隔离及真实设备行为验收。
- 本轮不安装或重启用户已安装的桌面客户端，不重置配对/Keychain，不读取真实 Vault 或凭据。
